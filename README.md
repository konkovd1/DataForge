# Personal portfolio

A one-page portfolio for independent data-platform engineering, with AI-platform work as a secondary capability.

## Run locally

1. Install a current Node.js LTS release (npm is included).
2. Install project dependencies:

   ```powershell
   npm install
   ```

3. Start the development server:

   ```powershell
   npm run dev
   ```

4. Open the local URL printed by Vite, usually `http://localhost:5173`.

Create a production build with `npm run build`; preview it locally with `npm run preview`.

## Before publishing

- Review the experience summaries and confirm every detail is safe to share.
- Deployment is intentionally not configured or performed yet.
